# Astra E78 Analysis Helpers

This directory contains the reusable evidence and scripts behind the expanded
FEQR mappings in `E78_Astra_047922_TableSearch.xdf`.

- `feqr_map.py` searches and evaluates FEQR relocation candidates.
- `feqr_exact_hits.csv` records exact relocation evidence.
- `build_feqr_xdf.py` adds proven FEQR entries and refreshes
  `feqr_mapping.csv`.
- `enrich_xdf_descriptions.py` rebuilds the detailed XDF descriptions.

Generated bytecode, one-off TunerPro load-test matrices, crash candidates, and
binary/XDF snapshots do not belong here. The promoted working files are the
current source of truth, and earlier states remain available through Git.
